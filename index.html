Mode demo lokal. Firebase belum dikonfigurasi. Pesanan hanya tersimpan di browser ini dan belum dapat tersinkron ke perangkat lain. Ikuti panduan setup untuk mengaktifkan mode online.

Formulir pengajuan

Menu yang ingin dicetak

Pastikan nama menu sudah benar agar stiker tidak salah cetak.

Masukkan satu nama menu untuk setiap pengajuan. Jika ada menu lain, ajukan melalui formulir baru.

Cara pemesanan

Ajukan menu. Admin yang mengurus sisanya.

Setelah diajukan, admin akan mengatur jumlah stiker, lalu menyiapkan barcode untuk dicetak melalui printer thermal.

01Isi nama menu dengan benar.
02Tekan tombol Ajukan pencetakan.
03Admin memproses pesanan dari halaman admin.
